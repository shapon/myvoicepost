Public AI Endpoints — /api/v1/p/ (Guest, 55s limit)

Method Path Auth Request Body Response Notes
POST /api/v1/p/transcribe Public
  • audio string (base64) required
  • mimeType string optional — default: audio/mp4
  • durationSeconds number optional
  • success bool
  • originalText string
  • detectedLanguage string optional
 Auto language detection. Max 55s / 10MB for guests
POST /api/v1/p/transcribe_l Public
  • audio string (base64) required
  • mimeType string optional
  • language string required — BCP-47 code
  • durationSeconds number optional
  • success bool
  • originalText string
  • language string
 Language-specific transcription. Max 55s guest
POST /api/v1/p/polish Public
  • text string required — key is "text" (not "originalText")
  • language string optional — default: en
  • outputFormat string optional — default: professional
  • outputType string optional — default: message
  • success bool
  • originalText string
  • polishedText string
  • language string
  • outputFormat string
  • outputType string
 Request key is "text". Response key is "originalText".
POST /api/v1/p/translate Public
  • text string required — key is "text"
  • sourceLanguage string required
  • targetLanguage string required
  • outputFormat string optional — default: professional
  • success bool
  • originalText string
  • translatedText string
  • polishedText string
  • sourceLanguage string
  • targetLanguage string
  • outputFormat string
 Request key is "text". Response keys include both translatedText and polishedText.
GET /api/v1/p/tone-categories Public —
  • success bool
  • categories array
 List of tone transformation categories
POST /api/v1/p/transform-tone Public
  • text string required
  • tone string required
  • language string optional
  • success bool
  • transformedText string
 Apply tone transformation to text
POST /api/v1/p/process-url Public
  • url string required
  • outputFormat string optional
  • outputType string optional
  • success bool
  • text string
  • title string optional
 Extract & process text from YouTube URL or webpage
GET /api/v1/p/plans Public
  • all query bool optional — include hidden plans
  • plans array
 List subscription plans
GET /api/v1/p/stripe-config Public —
  • publishableKey string

⚠️ Critical Shape Differences: Public vs Authenticated endpoints

Endpoint pair Public request field Auth request field
/api/v1/p/polish vs /api/v1/a/polish text (string) originalText (string)
/api/v1/p/translate vs /api/v1/a/translate text (string) originalText (string)
/api/v1/p/polish outputFormat default "professional" "paragraph"
/api/v1/p/polish outputType default "message" "general"

The GET /api/v1/p/reset-password and POST /api/v1/p/reset-password share the same path — they are distinguished by HTTP method. The GET variant is the email deep-link redirect page (mobile app handoff); the POST variant is the actual password-reset action.
